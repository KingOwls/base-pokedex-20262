# Crowleth Pokédex · actualización unificada 2026-09-22

Esta actualización se aplica sobre el proyecto existente `base-pokedex-20262` y no crea una aplicación nueva.

## Cambios visibles

- El buscador global del header usa el autocomplete compartido.
- Las sugerencias muestran sprite pixel art, número de Pokédex y nombre.
- La búsqueda acepta nombre, número, prefijos y errores de escritura razonables.
- La lista de sugerencias se cierra al seleccionar, al presionar Escape o al hacer clic fuera.
- La consulta se limpia después de seleccionar un Pokémon para que el menú no quede ocupando pantalla.
- PokéArcade muestra ocho juegos dentro de una sola cuadrícula.
- Se integraron y rutearon PokéImpostor, Type Grid y BST Builder.
